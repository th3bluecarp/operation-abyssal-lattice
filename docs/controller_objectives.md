# Controller Objectives (hidden grading reference)

A high-quality investigator should eventually conclude:
- The primary campaign has two coordinated tracks:
  - Track A: AiTM/session theft + OAuth consent abuse against an executive assistant
  - Track B: malicious package / developer compromise -> GitHub ref abuse -> CI/OIDC -> AWS -> EKS -> export -> Box
- The tracks unify decisively when the cloud-generated Box artifact is externally downloaded by the same IP that drove the SaaS abuse.
- The research node coinminer is real but unrelated.
- One finance archiving workflow is benign and approved.
- A stale purple-team beacon appears in-window but is not attacker activity.
- Release-signing access is exposed but not proven used.
- A 10:48Z-ish data-event visibility change creates uncertainty but is not by itself proof of anti-forensics.
